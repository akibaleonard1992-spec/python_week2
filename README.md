# Simple Bill Calculator

This Python program asks the user for the price of one item and the quantity they want. It calculates the total cost and prints a friendly summary.

## How to Run

1. Make sure Python is installed.
2. Open a terminal in this project folder.
3. Run:

   ```bash
   python bill_calculator.py
   ```

4. Enter the item price and quantity when prompted.

## Example

```text
Enter the price of one item: 50
Enter the quantity: 3
3 items at 50.00 each = 150.00
```
